<details>
<summary>🐍 <b>Enable the animated contribution snake (HUD grid, click to expand setup)</b></summary>
<br>

GitHub strips inline `<script>` tags, so the animated contribution "snake" is generated by a GitHub Action instead of client-side JS — this is the standard trick every gamified profile README relies on for real motion.

1. In this profile repo, create `.github/workflows/snake.yml` with:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 */6 * * *"
  push:
    branches: [ main ]
  workflow_dispatch: {}

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: Sharavanakumar-Ramalingam
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ '{{' }} secrets.GITHUB_TOKEN {{ '}}' }}
```

2. Push it, let the Action run once, then drop this into your README:

```md
<img src="https://raw.githubusercontent.com/Sharavanakumar-Ramalingam/Sharavanakumar-Ramalingam/output/github-contribution-grid-snake-dark.svg" width="100%"/>
```

Your commit graph will then animate as a snake eating its way through your contribution squares — fully live, no JS needed.
